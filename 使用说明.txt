  ZCode 代理面板 · 使用说明
═══════════════════════════════════════════════

【这是什么】
一套本地工具，把智谱 GLM 编程套餐（免费额度/编程套餐）变成标准
OpenAI / Anthropic 接口，供 Claude Code、Codex、网页聊天等使用。
核心是本地签名转发：工具只管连本机，签名和身份都由代理处理。
引擎直接以源码运行（Bun 运行器 + TypeScript），无任何编译产物。

【文件夹里有什么】
  core\                引擎（TypeScript 源码 + runtime.exe 通用运行器）
  zcode_panel.py       中文图形面板源码（Python 标准库，零 pip 依赖）
  ZCode面板.bat        双击打开面板（便携式，不写死路径）
  config.yaml          配置文件（密钥/模型/端口都在这里）
  app.ico              面板自制图标
  使用说明.txt         本文件

【交流群】
  1091692024 （加群链接：面板状态区与聊天页顶部点击直达）

【环境要求】
  · Windows 10/11 x64
  · 双击面板方式：需要 Python 3.10+（带 tkinter）。bat 会自动找 pythonw。
  · 不想装 Python：在 core 目录执行 runtime.exe run src/index.ts，
    用自带终端面板（按 l 登录、按 s 启动、按 q 退出），功能一样。

【第一次使用，三步】
  1. 双击 ZCode面板.bat → 面板打开
  2. 点【OAuth授权】→ 浏览器弹出 → 登录智谱并授权
  3. 点【启动代理】（变绿 = 运行中）→ 完成

【填到工具里的三样东西（面板"连接信息"区可一键复制）】
  接口地址：http://127.0.0.1:8080/v1
            ★ 必须填本机代理地址！不要直连 zcode.z.ai 等上游，
              直连会被签名校验拒绝（报 "signing credential" 错）。
  API 密钥：config.yaml 里的 proxyApiKey（面板上显示的就是它）
  默认模型：glm-5.3-flash（免费额度套餐实测只有 glm-5.3 和
            glm-5.3-flash 可用，其余模型会报 3006 不在套餐内）

【常用按钮】
  启动/停止代理        开关，运行时变绿
  OAuth授权 / 退出登录 智谱账号 OAuth 登录管理
  切换服务商           Z.AI（国际）↔ 智谱（国内）
  切换套餐             coding-plan（编程套餐）↔ start-plan（免费额度）
  获取可用模型         手动立即探测一次套餐支持的模型
  打开网页聊天         本地聊天测试页 http://127.0.0.1:8081
  清空日志 / 打开配置文件

【全自动检测（无需点击）】
  · 余额：代理运行中每 30 秒自动刷新进度条（各模型 剩余/总量，
    同名额度桶按到期时间区分）
  · 可用模型：面板启动、代理启动时各自动探测一遍，之后每 30 分钟一次，
    套餐新增/下架模型会自动更新到配置和下拉列表
  · 登录状态、端口、版本：自动轮询
  · 聊天页：撞到并发限流自动重试（最多等 30 秒），基本无感

【重要限制 · 必看】
  · 免费额度（start-plan）并发上限以账号实时为准（实测约 2-3 个，
    且会被同账号的其他会话分掉）：撞上就是 429/3008"并发超限"，
    聊天页已自动重试缓解，重试仍失败会提示稍等再发。
  · glm-5.3 思考型响应占用通道久，容易撞限流；
    glm-5.3-flash 快进快出，日常测试建议默认用它。
  · proxyApiKey 已启用校验：不带或填错密钥的请求会被 401 拒绝。
    网页聊天不受影响（自动带密钥）。

【换电脑 / 分发】
  1. 整个文件夹拷走即可（引擎跑源码，免安装）。
  2. 登录凭据不在本文件夹，在用户目录的 .zcode-proxy\credentials.json
     （本机当前位于 Instance 的 home 下）。新机器上把 credentials.json
     放到 C:\Users\<用户名>\.zcode-proxy\ 就不用重新登录；
     或者直接在面板点【OAuth授权】重新登一次。
  3. 新机器需要 Python（带 tkinter）才能用图形面板，否则用 core 里的
     runtime.exe 直接跑源码自带终端面板。
  4. 引擎升级：拿到新版本源码后，覆盖 core\src 目录内容即可
     （配置和登录都不受影响）。
